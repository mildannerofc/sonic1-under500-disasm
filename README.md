# Sonic 1 - Under 500 Disassembly

A ROM Hack made by Mildanner with modifications such as improved/extended debug mode, simple palette change and some bug fixes. Includes Error Handler.

Recently, the disassembly has been upgraded and now it has their own flags to control on building **Under 500** Hack (Eventually on progress).

Please make sure that the latest changes you see in here will not match the latest release due to having some tweaks and minor improvements.

Original disassembly by Sonic Retro.

# Frequently Asked Questions
Here are questions related to Sonic 1 - Under 500 and ROM Hacking Scene.

## Can I study the fixes used in this disassembly?
Sure thing, you can follow how it's done and credit the guide source.
## Where can I find the sprites used for Sonic?
Please give credit from content part you are using and don't forget to credit the author.
## What's Sonic 1 Under 500 and Under Neat?
Under 500 assemble the debug mode fixes and alternate world of video game era including fixes, extensions and stuff unlike. "Under Neat" is the same thing but way clean and made with few personalizations but also suffered some controversy about it being lazy palette edit and zero effort in levels.
## Can I study this disassembly fixes?
Feel free to do.
## Where do I find the sprites used for Sonic?
You can find the sprite sheet source on Spriters Resource in there [(Click on me)](https://www.spriters-resource.com/custom_edited/sonicthehedgehogcustoms/sheet/95696/). Remember to credit the sprite creators of the sheet before using it in your ROM Hack.
## Can I recreate this disassembly in Sonic Clean Engine?
Probably, you cannot since it uses ASM68K Branch. A good example is to use the palette edits, if you are eventually making actual stories of it. Make sure to credit the author who made the lore of project.
## Does this disassembly build on Linux?
You can, but if you find anything related to Linux. Feel free to ask, Wine is a tool for running Windows programs on Linux.
## How can I learn ASM coding?
If you don't know anything about ASM68K and how the code works (Computer Language as example), read the [assembly guide](https://mrjester.hapisan.com/04_MC68/) made by MarkeyJester or learn code from other disassemblies.
